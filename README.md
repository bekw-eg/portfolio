# Berdibek Egeubay — 2.5D-портфолио

Интерактивное портфолио «The Void»: парящие 3D-острова из эндерняка в космосе (Three.js, ортографическая камера сбоку). Скролл опускает камеру сквозь пустоту, поверх сцены — HTML-слой.

**Механики:** экран входа со звуком и генеративной 8-bit музыкой, квест — 7 осколков технологий спрятаны на островах (клик → летят в хотбар, прогресс сохраняется), верстак с проектами, путь-таймлайн с кораблём, «Книга ответов» обо мне, портал внизу загорается от осколков и ведёт к контактам. Воксельный аватар в наушниках смотрит за курсором и машет при клике.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статическая сборка в dist/ (base: './', подходит для GitHub Pages)
```

## Структура

| Файл | Что внутри |
|---|---|
| `src/data.js` | **Весь контент**: профиль, контакты, стек (хотбар + цвета осколков), проекты и рецепты, путь `journey`, книга `book`, команды чата |
| `src/textures.js` | Процедурные пиксельные текстуры блоков 16×16 и иконки предметов (Canvas, без Three.js) |
| `src/blocks.js` | Реестр блоков: текстуры граней, свечение, прозрачность, **замена на `.glb`** |
| `src/world.js` | Острова пустоты, дальний слой, позиции осколков `SHARDS`, портала и аватара, высоты камеры `LEVELS` |
| `src/scene.js` | Three.js: `OrthographicCamera`, `InstancedMesh` (1 draw call на тип блока), `DirectionalLight` + `HemisphereLight`, параллакс, частицы, копание блоков кликом |
| `src/sound.js` | 8-bit звуки на Web Audio API + Mute (сохраняется в localStorage) |
| `src/ui.js` | HTML-слой: хотбар с тултипами, верстак, достижения, контакты, чат с автодополнением |
| `src/main.js` | Связка скролла, UI и сцены; Three.js грузится динамически только на десктопе |

## Шрифт

Сайт на английском и использует **Blockcraft** — собственный пиксельный шрифт в духе интерфейса Minecraft (глифы 5×7, пропорциональный). Глифы описаны пикселями в `scripts/build-font.mjs`; после правок пересобери шрифт:

```bash
npm run font   # → src/assets/fonts/Blockcraft.otf
```

1 пиксель глифа = `font-size / 8`, поэтому размеры текста лучше держать кратными 8px (16, 24, 32…), тогда буквы остаются чёткими.

## Свои 3D-модели из Blender

1. Экспортируй модель в `.glb` (1 блок = 1×1×1 м, центр в начале координат).
2. Положи в `public/models/`.
3. В `src/blocks.js` добавь блоку поле `model: 'models/имя.glb'`.

Сцена загрузит модель через `GLTFLoader` и подставит её вместо кубов во всех позициях этого блока.

## Управление

- Скролл — спуск по уровням; движение мыши — параллакс камеры.
- `1–7` — выбор слота хотбара; наведение — тултип с описанием.
- `/` или `T` — чат: `/cv`, `/contacts`, `/shards`, `/music`, `/mute`, `/help` (Tab — автодополнение).
- Клик по кристаллу — собрать осколок; клик по аватару — помашет.
- Клик по блоку — сломать его (бедрок не ломается).

На экранах уже 768 px и на сенсорных устройствах 3D отключается: остаётся лёгкий 2D-интерфейс с пиксельными фонами. Three.js при этом не загружается.

Старая версия сайта лежит в `legacy/`.
